## What the adapter changes, and what it does not

- **Invocation only.** Under Codex this skill is invoked explicitly with the
  `$` prefix form of its name; the Claude source's slash form is documentation of
  the other runtime, not an instruction to emit. Natural-language activation is
  preserved exactly as the description above states — it is not disabled.
- **Tool names only.** Every Claude tool named inside the canonical payload binds
  to its Codex-native equivalent through the table in `codex-runtime.md`. Inputs,
  authority, pause points, returned data and continuation are unchanged. A
  surface that cannot preserve a gate blocks the run; it never falls back.
- **Asset paths only.** Skill-relative references inside the payload resolve
  against this directory and `../shared/`. Deterministic helpers resolve through
  the order documented in `codex-runtime.md`, Codex roots first, and never by
  reading or writing Claude installation state.
- **Nothing else.** No mode, flag, trigger, question, gate, refusal, check,
  write, report, artifact, handoff, review or retry is added, removed, reordered
  or weakened here. If following the payload on Codex appears to require one of
  those changes, stop and raise it as a new `DEV-CX` record instead.
